# 皮肤设置

问卷支持调整答题端的皮肤外观，常用于让问卷与游戏或被嵌页面的风格保持一致。在编辑页左侧点击「皮肤」进入皮肤设置。页面左侧选择皮肤，中间实时预览效果，右侧调整颜色和背景。

### 选择皮肤

左侧面板有两个标签：

* 推荐皮肤：系统提供的预设皮肤，点击即可套用。新建问卷默认使用「默认」皮肤。
* 我的皮肤：当前账号保存过的自定义皮肤，可在其他问卷中重复使用。

### 预览效果

中间预览区顶部可切换三种预览模式，设置的改动会立即显示在预览中：

| 模式    | 说明                     |
| ----- | ---------------------- |
| 手机    | 查看移动端答题效果              |
| 电脑    | 查看 PC 端答题效果            |
| 内嵌SDK | 定制化问卷可 查看问卷内嵌到游戏中的显示效果 |

### 自定义皮肤

右侧「自定义皮肤」中可以单独调整以下颜色。点击色块选择颜色，点击右侧的 ↻ 按钮恢复为默认值。

| 配置项   | 作用范围                            |
| ----- | ------------------------------- |
| 主题色   | 问卷主色调，用于开始/提交/翻页按钮、答题进度、选项选中状态等 |
| 答题背景  | 欢迎语、题目、结束页所在内容区的背景色             |
| 题干颜色  | 题目标题的文字颜色                       |
| 选项颜色  | 选项的文字颜色                         |
| 备注颜色  | 题目备注的文字颜色                       |
| 提示语颜色 | 量表题提示等提示类文字的颜色                  |

### 页面背景

页面背景是内容区外侧的网页底色，支持两种方式：

* 颜色：从预设色块中选择，或点击最后一个彩色色块自定义颜色。
* 图片：上传图片作为页面背景。

内容区透明度：拖动滑块调整答题内容区的透明度，默认 100%（完全不透明）。使用背景图片时适当调低，可以让背景图透出来。
