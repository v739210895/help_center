# 答题数据在线查看

在统计页可在线查看答卷详情，以快速了解问卷各题的回收数据及回收情况。

{% hint style="info" %}
用户未回答的题目答案处显示为空。
{% endhint %}

支持按指定条件进行数据筛选，根据指定条件查看部分答卷。
