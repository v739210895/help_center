# 问卷标题编辑

## 修改问卷标题文本内容

在欢迎页，点击问卷标题编辑框即可修改问卷标题文本，编辑完成后点击空白处自动保存。

{% hint style="info" %}
问卷标题限制在50字以内。
{% endhint %}
